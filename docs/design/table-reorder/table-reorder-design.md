## 2. 文書の目的

本書は、Table Reorder要件定義書で定義されたMVP要件を、Gutenbergブロックエディター上で実現するための基本設計を定める。

本書では、次を扱う。

- 通常時と並べ替えモードの画面
- 並べ替えモードの開始と終了
- ドラッグハンドル
- ポインターによる行DnD
- キーボードによる行DnD
- 行データの保持とUndo
- `rowspan`を考慮した移動制約
- `colspan`だけを含む行の扱い
- エラー表示と通知
- アクセシビリティ
- iframe・非iframeの編集環境への対応

背景、目的、対象範囲、対象外および受け入れ条件は要件定義書を正とする。

## 3. 対象範囲

### 3.1 対象

- コアTableブロック
- `tbody`内の本文行
- 同じ`tbody`内での一行単位のDnD
- ポインター操作
- キーボード操作

### 3.2 対象外の領域

- `thead`のヘッダー行
- `tfoot`のフッター行
- ヘッダー、本文、フッターをまたぐ移動

## 4. 設計原則

1. 行の移動方法はDnDだけとする。
2. 通常のセル編集と行の並べ替え操作を分離する。
3. 並べ替えモード中だけ行DnDを有効にする。
4. ポインターとキーボードの両方で同じ移動制約を適用する。
5. コアTableブロックの保存形式を変更しない。
6. 行を構成するセル内容、セル属性および装飾を行単位で保持する。
7. 一回の確定した行移動を、一回のUndo操作として記録する。
8. 禁止された操作では表データを変更しない。
9. `rowspan`の結合範囲を分断しない。
10. 操作状態と結果はスクリーンリーダーへ通知し、禁止操作のエラーは画面表示とスクリーンリーダー通知の両方で伝える。
11. iframe・非iframeのどちらでも、選択中のTableブロックが描画されている編集領域を基準にDOM、座標、イベントおよびDnD表示を扱う。

### 4.1 iframe・非iframe対応

Table Reorderは、投稿エディターがiframeまたは非iframeのどちらで動作する場合も、同じ機能要件を満たす。

- 選択中Tableブロックの要素から編集領域の`document`と`window`を取得し、グローバルな`document`または`window`が常に編集領域を表すとは仮定しない。
- 本文行の検索、行位置の測定、イベント登録、Observer登録およびフォーカス操作は、Tableブロックが存在する編集領域を対象とする。
- ドラッグハンドル、挿入位置およびDnD中の表示は、Tableブロックと同じ座標系で扱う。
- ブロックツールバーと並べ替え状態の連携は、WordPressの公開APIとReactの状態を通じて行い、iframe内外のDOMを直接結合することを前提にしない。
- 並べ替えモードの終了またはコンポーネントの破棄時は、対象の編集領域へ登録したイベントとObserverを解除する。
- 非iframe環境では同じ処理がメイン文書を対象として動作し、環境ごとに異なる製品仕様や操作を追加しない。

## 5. UI設計

### 5.1 通常時

通常時は、既存のTableブロックと同じようにセルを編集できる。

```text
ブロックツールバー
[行を並べ替え]

┌────────┬────────┐
│ セル   │ セル   │
├────────┼────────┤
│ セル   │ セル   │
└────────┴────────┘
```

- ドラッグハンドルは表示しない。
- 行DnDは開始できない。
- ブロックツールバーに「行を並べ替え」を表示する。

### 5.2 並べ替えモード

「行を並べ替え」を押すと並べ替えモードへ移行する。

```text
ブロックツールバー
[並べ替えを終了]

   ┌────────┬────────┐
⠿  │ セル   │ セル   │
   ├────────┼────────┤
⠿  │ セル   │ セル   │
   └────────┴────────┘
```

- `tbody`内の各本文行の左側にドラッグハンドルを表示する。
- 行DnDはドラッグハンドルから開始する。
- セル内容は表示したまま保持する。
- ヘッダー行とフッター行にはドラッグハンドルを表示しない。
- ブロックツールバーの操作を「並べ替えを終了」へ切り替える。

### 5.3 ドラッグハンドル

各ドラッグハンドルは、対応する本文行を一行単位で移動するための操作要素とする。

- ポインターでドラッグできる。
- キーボードでフォーカスできる。
- 対象行と操作内容が分かるラベルを持つ。
- `rowspan`の結合範囲に含まれ、移動できない行ではDnDを開始できない状態を示す。
- 移動可否を色だけで表現しない。

ラベルは、少なくとも対象行の位置と行を並べ替える操作であることが分かる内容とする。

## 6. 状態設計

Table Reorderは、次の状態を持つ。

| 状態 | 説明 |
|---|---|
| 通常 | セル編集を行う状態。ドラッグハンドルは表示しない。 |
| 並べ替え待機 | ドラッグハンドルを表示し、DnDを開始できる状態。 |
| ポインターDnD中 | ポインターで移動元行と移動先候補を操作している状態。 |
| キーボードDnD中 | キーボードで移動元行と移動先候補を操作している状態。 |

並べ替えモードおよびDnD中の状態は編集画面上の一時状態として扱い、Tableブロックの保存形式には追加しない。

DnD中は、少なくとも次を一時的に保持する。

- 移動元の行
- 移動開始前の行順序
- 現在の移動先候補
- 移動先候補が有効かどうか
- 同じ移動試行でエラーを通知済みかどうか

## 7. 行データと更新方式

### 7.1 移動単位

移動単位は、`tbody`内の一つの本文行とする。

移動時は、行に含まれる次の情報をまとめて保持する。

- 各セルの内容
- 各セルの属性
- 各セルの装飾
- 行内のセル順序
- `colspan`などセルに設定された情報

セルを作り直したり、内容だけを別の行へコピーしたりせず、既存の行データの順序を変更する。

### 7.2 保存形式

行順序は、コアTableブロックが保持している本文行データの配列順として反映する。

新しい保存属性や独自HTMLは追加せず、コアTableブロックの保存形式を維持する。

### 7.3 更新タイミング

表データは、移動先が有効であり、DnDが確定したときだけ更新する。

- ドラッグ中またはキーボードで移動先を選択している途中では、確定済みの表データを更新しない。
- 禁止位置への操作では更新しない。
- キャンセル時は開始前の順序を維持する。

### 7.4 Undo

一回のDnD確定につき、行順序の更新を一回だけ実行する。

これにより、一回の行移動を一回のUndo操作で開始前の順序へ戻せるようにする。

## 8. ポインターによるDnD

### 8.1 操作フロー

1. 並べ替えモードで移動対象行のドラッグハンドルを押す。
2. 対象行が移動可能か確認する。
3. 移動可能な場合はポインターDnDを開始する。
4. ポインター位置から移動先候補となる行間を求める。
5. `rowspan`の制約を使って移動先候補を検証する。
6. 有効な位置では挿入位置を示す。
7. 有効な位置でドロップした場合は行順序を一回更新する。
8. 完了をスクリーンリーダーへ通知する。

### 8.2 移動先の表示

- 有効な移動先には挿入位置を示す。
- `rowspan`を分断する禁止位置には挿入線を表示しない。
- 移動元と同じ順序になる位置では表データを変更しない。

### 8.3 禁止操作

次の場合は表データを変更しない。

- 移動元行が`rowspan`の結合範囲に含まれる。
- 移動先が`rowspan`の結合範囲の途中である。
- 移動によって`rowspan`がまたぐ境界を越える。
- 移動先が`tbody`の外である。

禁止された移動を試みた場合は、規定のエラーを一回だけ通知する。

## 9. キーボードによるDnD

### 9.1 操作キー

| キー | DnD開始前 | DnD開始後 |
|---|---|---|
| `Space` | DnDを開始する | 移動を確定する |
| `Enter` | DnDを開始する | 移動を確定する |
| `ArrowUp` | 操作しない | 移動先候補を一行上へ変更する |
| `ArrowDown` | 操作しない | 移動先候補を一行下へ変更する |
| `Escape` | 操作しない | DnDをキャンセルする |

### 9.2 操作フロー

1. 並べ替えモードで対象行のドラッグハンドルへフォーカスする。
2. `Space`または`Enter`を押す。
3. 対象行が移動可能な場合はキーボードDnDを開始する。
4. `ArrowUp`または`ArrowDown`で移動先候補を一行ずつ変更する。
5. 候補を変更するたびに`rowspan`の制約を検証する。
6. 有効な場合は移動先候補を更新し、現在位置を通知する。
7. 禁止位置の場合は移動先候補を変更せず、エラーを一回だけ通知する。
8. `Space`または`Enter`で確定した場合は行順序を一回更新する。
9. `Escape`でキャンセルした場合は開始前の順序を維持する。

### 9.3 フォーカス

- DnD開始時は、操作中のドラッグハンドルを基準に操作を継続する。
- 確定後は、移動後の対象行を操作できる位置にフォーカスを維持する。
- キャンセル後は、移動元行のドラッグハンドルへフォーカスを戻す。

## 10. 結合セルの保護

### 10.1 `rowspan`範囲の判定

本文行を上から順に確認し、`rowspan`が2以上のセルごとに、そのセルが占有する開始行から終了行までを結合範囲として扱う。

```text
行1  ┌────────┬────────┐
     │ rowspan│ セル   │
行2  │   2    ├────────┤
     │        │ セル   │
     └────────┴────────┘
```

この例では、行1と行2を一つの結合範囲として扱う。

### 10.2 移動元行の制約

`rowspan`の結合範囲に含まれる行は移動できない。

- `rowspan`を持つセルが開始する行
- `rowspan`によって占有される後続行

のどちらも移動対象にしない。

### 10.3 移動先の制約

次の位置は移動先として扱わない。

- `rowspan`の結合範囲の途中
- 移動によって`rowspan`の結合範囲をまたぐ位置
- `tbody`の外

`rowspan`の結合範囲は、行移動で分断できない境界として扱う。

移動元と移動先が結合範囲を挟んで反対側にある場合は、結合範囲を越える移動として禁止する。

### 10.4 `colspan`だけを含む行

`colspan`は行内の横方向の結合であるため、`rowspan`の制約に該当しない場合は、その行を一行単位で移動できる。

- `colspan`の値を変更しない。
- セル内容、セル属性および装飾を保持する。
- 行内のセル順序を変更しない。

## 11. エラーと通知

### 11.1 エラーメッセージ

`rowspan`を分断する操作では、次のメッセージを使用する。

> 結合セルを分断する位置には行を移動できません。結合を解除してから並べ替えてください。

### 11.2 通知方法

通知対象に応じて、次の方法を使い分ける。

- 操作状態と操作結果は、スクリーンリーダーへ通知する。
- 禁止操作のエラーは、画面上で確認できる通知とスクリーンリーダーが読み上げる通知の両方で伝える。

操作状態を一行変更するたびに画面通知を表示するなど、要件にない画面通知は追加しない。

### 11.3 通知対象

次の操作状態と操作結果は、スクリーンリーダーへ通知する。

- 並べ替えモードの開始
- 並べ替えモードの終了
- DnDの開始
- 現在の移動先
- 移動の完了
- キャンセル

移動禁止は、画面表示とスクリーンリーダー通知の両方で伝える。

### 11.4 エラー通知回数

同じDnD開始から確定またはキャンセルまでを一回の移動試行とする。

一回の移動試行中は、禁止位置の違いにかかわらず、エラーメッセージを一回だけ表示し、スクリーンリーダーへ一回だけ通知する。新しいDnDを開始したときは、通知済み状態をリセットする。

## 12. アクセシビリティ

- すべての本文行のドラッグハンドルをキーボードでフォーカスできるようにする。
- ドラッグハンドルに対象行と操作内容が分かるラベルを付ける。
- `Space`または`Enter`でDnDを開始および確定できるようにする。
- `ArrowUp`と`ArrowDown`だけで移動先を変更できるようにする。
- `Escape`で変更を破棄できるようにする。
- 操作状態と結果をスクリーンリーダーへ通知する。
- 移動可能、移動禁止、フォーカスおよび挿入位置を色だけで表現しない。
- キーボード操作だけで、開始から確定またはキャンセルまで完了できるようにする。

## 13. 並べ替えモードの終了

ブロックツールバーの「並べ替えを終了」を押すと通常状態へ戻る。

終了時は次を行う。

- ドラッグハンドルを非表示にする。
- 行DnDを無効にする。
- 通常のセル編集へ戻す。
- 並べ替えモードの終了をスクリーンリーダーへ通知する。

DnD中に「並べ替えを終了」を押した場合は、進行中のDnDをキャンセルしてから通常状態へ戻る。

- 移動開始前の行順序を維持し、表データを変更しない。
- 移動元、移動先候補およびエラー通知済み状態など、DnD中の一時状態を破棄する。
- フォーカスは、通常状態へ切り替わったブロックツールバーの「行を並べ替え」に維持する。

確定済みの行順序は維持する。

## 14. MVPの対象外

次は本設計の対象外とする。

- 上下移動ボタンによる並べ替え
- 列の並べ替え
- 複数行の同時移動
- 結合セルを含む行グループ全体の移動
- 行の複製
- CSVの入出力
- 値による自動ソート

## 15. 確認観点

| 観点 | 確認内容 |
|---|---|
| 通常時 | ドラッグハンドルが表示されず、通常どおりセルを編集できる。 |
| モード切替 | 並べ替えモードを開始および終了できる。DnD中に終了した場合は、進行中のDnDがキャンセルされ、開始前の順序を維持して通常状態へ戻る。 |
| ポインターDnD | 本文行を同じ`tbody`内の有効な位置へ移動できる。 |
| キーボードDnD | 開始、上下移動、確定、キャンセルをキーボードだけで行える。 |
| データ保持 | セル内容、セル属性、装飾および行内のセル順序が保持される。 |
| Undo | 一回の移動を一回のUndoで元に戻せる。 |
| `rowspan` | 結合範囲に含まれる行、結合範囲の途中、結合範囲を越える移動が拒否される。 |
| `colspan` | `rowspan`の制約がなければ、`colspan`だけを含む行を移動できる。 |
| 禁止操作 | 表データが変更されず、一回の移動試行につきエラーが一回だけ表示および通知される。 |
| 通知 | 操作状態と結果はスクリーンリーダーで確認でき、禁止操作のエラーは画面表示とスクリーンリーダーの両方で確認できる。 |
| 保存形式 | コアTableブロックの保存形式が変更されない。 |
| エディター環境 | iframe・非iframeのどちらでも、対象Tableの取得、ハンドル配置、ポインターとキーボードのDnD、DnD中の表示、通知、フォーカスおよび後始末が同じ要件どおりに動作する。 |
