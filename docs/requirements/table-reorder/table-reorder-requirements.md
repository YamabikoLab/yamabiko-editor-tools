# Table Reorder 要件定義書

## MVP：Tableブロックの行の並べ替え

| 項目 | 内容 |
|---|---|
| 機能名 | Table Reorder |
| 対象 | WordPress Gutenberg のコア Tableブロック |
| 初期範囲 | 本文行の並べ替え |
| 方針 | 必要なときだけ並べ替えモードを有効にする |

## 背景・関連Issue

### #54025 Table: Reorder rows manually

Tableブロックでは、行の順番を変更するために空行を追加し、各セルの内容を一つずつコピーし直す必要があるという具体的な不便が報告されている。

Issueでは、この操作を改善する方法として、行を直接移動できるドラッグハンドルが提案されている。

- https://github.com/WordPress/gutenberg/issues/54025

### #6923 Table block: flesh out editor features

Tableブロックの編集機能を拡充するための、59件のコメントがある長期Issueであり、行やセルの操作を含む高度な表編集機能について議論されている。

Issue本文では、これらの機能をWordPressコアへ追加するか、Tableブロックを拡張するプラグインへ委ねるかが明示的に検討されている。

本機能は、コアTableブロックの保存形式を変更せず、プラグインとして行の並べ替え機能を追加する方針とする。

- https://github.com/WordPress/gutenberg/issues/6923

## 1. 目的

Tableブロックの行を、セル内容をコピーし直すことなく、安全に並べ替えられるようにする。

## 2. 対象範囲

- Tableブロックの本文（`tbody`）の行を対象とする。
- 行の移動方法はDnDのみとする。
- ポインターとキーボードの両方でDnDを操作できる。
- ヘッダー、本文、フッターの間をまたぐ移動は行わない。
- 通常のセル編集と並べ替え操作を分離する。

## 3. 操作の流れ

1. Tableブロックを選択する。
2. ブロックツールバーの「行を並べ替え」を押す。
3. 行の左側にドラッグハンドルを表示する。
4. ポインターまたはキーボードで行を移動する。
5. 「並べ替えを終了」を押して通常編集へ戻る。

## 4. 機能要件

| ID | 項目 | 要件 |
|---|---|---|
| FR-01 | 並べ替えモード | ボタンを押したときだけ行の並べ替え操作を有効にする。 |
| FR-02 | 行のDnD | 本文行をドラッグし、同じ本文内の別の位置へ移動できる。 |
| FR-03 | キーボードDnD | ドラッグハンドルへフォーカスし、キーボードでDnDの開始、移動、確定、キャンセルを行える。 |
| FR-04 | データ保持 | 移動時にセル内容、セル属性、装飾をそのまま保持する。 |
| FR-05 | Undo | 一回の移動を一回のUndo操作として元に戻せる。 |
| FR-06 | 終了 | 並べ替えモードを終了すると、ドラッグハンドルを非表示にする。 |

### キーボードDnDの操作

- `Space` または `Enter` でDnDを開始する。
- `ArrowUp` と `ArrowDown` で移動先を一行ずつ変更する。
- `Space` または `Enter` で移動を確定する。
- `Escape` で移動をキャンセルし、開始前の順序へ戻す。
- DnDの開始、現在の移動先、確定、キャンセルをスクリーンリーダーへ通知する。

## 5. 結合セルの保護

- 縦方向の結合セル（`rowspan`）がまたぐ境界を越えて行を移動できない。
- `rowspan` の結合範囲の途中へ行を挿入できない。
- 初期版では、`rowspan` の結合範囲に含まれる行は移動できない。
- `colspan` だけを含む行は、行単位で安全に移動できる場合は移動を禁止しない。
- 禁止された位置への移動を確定しても、表データを変更しない。
- ポインターによるドラッグ中は、禁止位置に挿入線を表示しない。
- キーボードDnDで禁止位置への移動を試みた場合は、移動先を変更しない。
- エラーメッセージは、一回の移動試行につき一回だけ表示する。
- 画面通知とスクリーンリーダー通知の両方を行う。

### エラーメッセージ

> 結合セルを分断する位置には行を移動できません。結合を解除してから並べ替えてください。

## 6. アクセシビリティ

- 各ドラッグハンドルはキーボードでフォーカスできる。
- 各ドラッグハンドルに、対象行と操作内容が分かるラベルを付ける。
- キーボードDnDだけで、移動の開始から確定またはキャンセルまで完了できる。
- DnDの開始、移動先、移動完了、移動禁止、キャンセル、並べ替えモード開始・終了を読み上げる。

## 7. 対象外

- 上下移動ボタンによる並べ替え
- 列の並べ替え
- 複数行の同時移動
- 結合セルを含む行グループ全体の移動
- 行の複製
- CSVの入出力
- 値による自動ソート

## 8. 完了条件

- 並べ替えモード以外では、通常どおりセルを編集できる。
- 本文行をポインターまたはキーボードによるDnDで並べ替えられる。
- キーボードDnDで開始、移動、確定、キャンセルを行える。
- 移動後もセル内容とセル属性が保持される。
- `rowspan` を分断する移動は拒否され、エラーが表示される。
- 禁止された操作では表データが変更されない。
- 一回の移動をUndoで元に戻せる。
- キーボードとスクリーンリーダーで操作結果を確認できる。
